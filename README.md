Smart India Hackathon 2026 — SIH26056
# ✈️ Airfare Price Index web scrapper
problem statement: 	"Development of a Real-time Airfare Price Index for India through Automated Web Scraping of Airline and Online Travel Aggregator Portals for Augmentation of the Consumer Price Index (CPI)."


📌 Overview

A full-stack platform that **collects, stores, cleans, analyzes airfare prices** using web scraping, Machine Learning, databases, and React JS.

## 🔄 Workflow

```text
Web Scraping
     ↓
Data Cleaning & Processing
     ↓
Machine Learning
     ↓
Database
     ↓
Backend API
     ↓
React Frontend
```

## 🛠️ Tech Stack

* **Web Scraping:** Python, Playwright
* **Database:** Postgres SQL
* **Backend:** Node.js, Express.js
* **ML & Data Processing:** Python, Pandas, NumPy, Scikit-learn
* **Frontend:** React.js
* **Visualization:** Charts / Graphs

## 🚀 Key Features

* Automated airfare data collection
* Historical price storage
* Data cleaning and preprocessing
* Airfare trend analysis
* Interactive React dashboard
* Airline and route comparison

## 🎯 Goal

To transform continuously collected airfare data into **useful price trends and predictions**, helping users make better flight-booking decisions.
